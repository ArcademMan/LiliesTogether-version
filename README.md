# Lilies Together - version

This repository holds only the number of the latest release of **Lilies Together**, the co-op mod for
ENDER LILIES, in `latest.txt`.

When the game starts, the mod reads that file once and, if a newer
version exists, shows a message on the title screen telling the player to download it from NexusMods.

The mod never downloads or runs anything: the file contains only a version number like `0.16.3`, and
anything else is ignored. The check can be turned off in the mod's settings.
